# 🛡️ Política de Segurança — LMS BNCC Computação

A segurança e a privacidade dos dados de alunos, professores e escolas públicas são prioridades absolutas neste projeto.

---

## 🔒 Versões Suportadas

Atualmente fornecemos suporte e atualizações de segurança para as seguintes versões:

| Versão | Suportada | Notas |
| :--- | :---: | :--- |
| **Cloudflare Workers / D1 (v1.x)** | ✅ Sim | Backend oficial recomendado para produção |
| **Node.js / Express / MySQL (legado)** | ⚠️ Manutenção | Compatibilidade para deploys locais |

---

## 🚨 Como Reportar uma Vulnerabilidade

Se você descobriu uma falha de segurança ou potencial vulnerabilidade na plataforma:

1. **NÃO crie uma Issue pública** para relatar a vulnerabilidade, pois isso pode expor dados escolares antes de uma correção ser disponibilizada.
2. Utilize o recurso oficial do GitHub: **[Report a vulnerability](https://github.com/LMS-COMPASSO/lms/security/advisories/new)** na aba *Security* deste repositório.
3. Caso a opção não esteja visível, envie um email com os detalhes técnicos para a equipe mantenedora (`admin@lms-bncc.edu.br` ou pelo perfil institucional).

### O que incluir no reporte:

- Uma descrição clara da vulnerabilidade.
- Passos reproduzíveis (como o problema pode ser identificado).
- Impacto potencial estimado (ex: visualização não autorizada de matrículas, falha de autenticação).
- Sugestão de correção, caso já tenha uma proposta.

---

## ⏱️ Nosso Processo de Resposta

- **Confirmação inicial:** Responderemos em até 48 horas confirmando o recebimento do relato.
- **Análise e Correção:** Avaliaremos o impacto e prepararemos uma correção prioritária.
- **Publicação:** Após a aplicação da correção, creditaremos publicamente quem reportou o problema (a menos que a pessoa prefira anonimato).

Agradecemos imensamente a cooperação responsável de toda a comunidade!
